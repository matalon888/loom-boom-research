How to use this

Wave 1 is the $4,550 TikTok pack — book all ten to post inside the same 72 hours so the hashtag reads as a movement, not ten separate ads. Wave 3 is the X builder pack, only after Wave 1 returns real numbers. Everything else is Wave 4: re-book whoever actually performed.

Fees are standard follower bands, not quotes. Open each creator's proof post before you offer — and negotiate on the views column, never the followers column.
